About My Journey

I am a Software Engineering student who is interested in understanding how computers, software, and the web work. During my studies, I have been learning different areas of computer science and software development.

Some of the subjects I am currently interested in include Web Development, Operating Systems, and Computer Networking. These subjects help me build a stronger foundation for developing software in the future.

What I Am Learning

Web Development

Web Development introduces me to technologies used to build websites. I am currently learning HTML and how semantic elements can make web pages easier to understand and more accessible.

Operating Systems

Operating Systems helps me understand how a computer manages processes, memory, files, and hardware resources. It also helps explain what happens between software applications and the computer hardware.

Computer Networking

Computer Networking teaches me how computers communicate with each other. I am learning concepts such as IP addresses, network devices, protocols, and how data travels across networks.

My Learning Goals

Some of my current learning goals are:

  • Improve my HTML and web development skills.
  • Understand how modern operating systems work.
  • Build a strong foundation in computer networking.
  • Develop practical software engineering projects.
  • Continue learning new technologies independently.

Useful Resources

One of the resources I use to learn more about HTML and Web Development is MDN Web Docs.

MDN provides documentation and examples for HTML, CSS, JavaScript, and many other web technologies.
